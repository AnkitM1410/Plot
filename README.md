# BTC 4-Year Cycle Plots

Daily Bitcoin 4-year cycle plots published to GitHub Pages.

## Setup

1. **Secrets** (under **Settings** > **Environments** > **For_Actions**):
   - `KAGGLE_USERNAME`
   - `KAGGLE_KEY`
2. **GitHub Pages** (under **Settings** > **Pages**):
   - Source: **GitHub Actions**

## Runs

- **Automated**: Daily at 03:00 UTC
- **Manual**: Via **Actions** > **Daily Cycle Plots & GitHub Pages Deploy** > **Run workflow**
